# FleetAMP v0.1.0 — Community Preview

FleetAMP v0.1.0 is the first packaged release for evaluation and controlled single-server pilots. It is an early pre-1.0 release, not a supported production release.

## Capabilities

- Persistent OpAMP agent inventory and agent detail views
- Active, Offline, and Retired lifecycle states
- Stable logical-agent reassociation after Collector or pod restarts
- SQLite-backed groups, assignments, configurations, and deployment history
- Group-based remote configuration deployment, status, history, and rollback
- Desired-versus-effective configuration visibility
- First-login administrator setup with Argon2id password verification
- Server-bound credential protection, authenticated sessions, CORS, and CSRF controls
- Optional HTTPS/WSS, bearer-token authentication, and OpAMP mTLS
- Linux systemd user and system service deployment assets

## Supported preview configuration

- One FleetAMP instance
- Local SQLite persistent storage
- Linux on amd64 or arm64
- OpenTelemetry Collector connected through the OpAMP Supervisor

## Known limitations

- No high availability or PostgreSQL backend
- No OIDC, multi-role RBAC, or approval separation
- No certificate-to-agent authorization mapping
- No Collector binary/package upgrade management
- No production-scale or performance certification
- No packaged Kubernetes deployment for FleetAMP
- Grafana Alloy is not yet a validated managed-agent target

Use this release in a test environment first. Back up the FleetAMP data
directory and SQLite database before every upgrade.

## Download and verify

Download the archive for your architecture together with `SHA256SUMS`:

- `fleetamp_0.1.0_linux_amd64.tar.gz`
- `fleetamp_0.1.0_linux_arm64.tar.gz`

Verify the download before extracting it:

```bash
sha256sum -c SHA256SUMS
tar -xzf fleetamp_0.1.0_linux_amd64.tar.gz
cd fleetamp_0.1.0_linux_amd64
./fleetamp --version
```

The archive includes systemd examples and the user-service installer. Read
`deploy/systemd/README.md` before installation.
