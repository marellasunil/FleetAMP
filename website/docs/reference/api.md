# REST API

FleetAMP exposes its current API under `/api/v1`. Key resources include agents, agent events, labels, groups and group members, configurations and validation, assignments, deployments, deployment summary, drift, and rollback.

The web UI and API currently share the HTTP listener on port `8080`. The API is evolving with FleetAMP; consumers should treat it as a development API until versioning and compatibility guarantees are formally published.
